# 픽셀로직 홈페이지 디자인세트

- 상태: 홈페이지 개편 시안
- 기준일: 2026-08-26
- 목적: `web-toolkit.app`을 픽셀로직의 공식 홈페이지로 전환하고 Google OAuth 브랜딩 심사에 필요한 브랜드·제품·데이터 이용 정보를 공개한다.

## 시각 방향

픽셀로직은 여러 앱을 직접 만들고 운영하는 독립 제품 스튜디오다. 홈페이지의 주인공은 픽셀 격자에서 실제 제품 화면이 조립되는 **제품 별자리**다. 장식용 파티클이 아니라 하나의 운영 주체가 서로 다른 제품을 연결한다는 의미를 갖는다.

첫 화면에서 다음 세 가지가 동시에 읽혀야 한다.

1. OAuth 앱 이름과 같은 `픽셀로직` 브랜드
2. 일상·배움·관계를 위한 모바일 앱을 만들고 운영한다는 기능 설명
3. 개인정보처리방침, 서비스 이용약관, 계정 및 데이터 삭제, 문의 경로

금지 패턴은 게임 UI, 균등 카드 격자, 근거 없는 성과 수치, 고객사 로고, 로그인 전용 화면, 과한 그라데이션 구체, 카드 안의 카드다.

## 정보 구조와 카피

### 헤더

- 로고: 기하학적 `PL` 모노그램 + `PIXELLOGIC / 픽셀로직`
- 내비게이션: `제품`, `원칙`, `데이터 이용`, `문의`
- 언어: `KO · EN`

### 히어로

- 제목: `작은 호기심을, 오래 쓰는 경험으로.`
- 설명: `픽셀로직은 일상·배움·관계를 위한 모바일 앱을 직접 만들고 운영합니다.`
- 주 행동: `픽셀로직 제품 보기`
- 보조 행동: `데이터 이용 원칙`
- 신뢰 문구: `Google 로그인은 계정 연결에 필요한 범위에서만 사용합니다.`

### 제품 쇼케이스

균등 카드 네 장을 만들지 않는다. 실제 화면의 종횡비와 제품 성격에 따라 서로 다른 크기의 창을 하나의 연결망에 배치한다.

| 제품        | 설명                           | 시각 신호                         |
| ----------- | ------------------------------ | --------------------------------- |
| 헤아림 사주 | 근거를 펼쳐 보여주는 사주 앱   | 한지색, 먹색, 짙은 초록           |
| TalkTalk    | AI와 이어가는 안전한 영어 대화 | 종이 레이어, 청록, 안전 종료 빨강 |
| Orbit       | 관계를 발견하는 소셜 퀴즈      | 짙은 우주색, 보라·하늘 궤도       |
| SideQuest   | 평범한 하루를 작은 모험으로    | 따뜻한 크림색, 탐험 노랑          |

각 제품 상세 링크는 준비된 공개 랜딩 또는 스토어 주소가 있을 때만 연결한다. 없는 주소를 임시 링크로 대체하지 않는다.

### 데이터 이용

홈페이지에 별도 섹션을 두어 다음 내용을 평문으로 설명한다.

- Google 로그인은 픽셀로직 계정 연결에 사용한다.
- 요청하는 Google 사용자 데이터와 접근·사용·저장·공유 방식은 실제 OAuth 범위와 구현을 기준으로 열거한다.
- 앱 데이터는 제품별로 구분하며, 공개 개인정보처리방침과 앱 안의 고지 내용이 일치해야 한다.
- 사용자는 앱에서 자신의 앱 데이터 또는 계정 삭제 범위를 확인하고 삭제를 요청할 수 있다.

실제 OAuth 범위가 확정되기 전에는 `이름과 이메일만 사용합니다` 같은 단정 문구를 만들지 않는다.

### 푸터

- `개인정보처리방침`
- `서비스 이용약관`
- `계정 및 데이터 삭제`
- `pixellogic.app@gmail.com`

위 링크는 로그인 없이 접근 가능하고 같은 소유 도메인 아래 정적 URL을 사용한다.

## 정책·삭제 화면

홈페이지 구현 뒤 정책 화면을 관성적으로 조립하지 않는다. 개인정보처리방침, 서비스 이용약관,
계정 및 데이터 삭제의 라이트·다크 시안을 먼저 확정하고 아래 공통 구조로 구현한다.

### 공통 문서 셸

- 헤더에는 홈페이지와 같은 `PL` 브랜드, `픽셀로직 홈`, `KO · EN`, 테마 전환을 둔다.
- 하위 문서이므로 `픽셀로직 홈`은 명시적인 이탈 수단이다. 브라우저 기록에 의존하는 백 버튼은 쓰지 않는다.
- 데스크톱은 왼쪽 목차 210px와 최대 760px 읽기 열을 사용한다.
- 모바일은 목차를 본문 앞의 가로 이동 링크로 바꾸고 읽기 열을 한 열로 만든다.
- 본문은 16px 미만으로 내리지 않고 행 길이는 62ch 이하로 제한한다.
- 섹션은 카드가 아니라 1px 구분선과 번호·제목으로 나눈다.

### 개인정보처리방침

- 신호색: `signal`
- 섹션: 수집하는 정보, Google 사용자 데이터, 이용 목적, 처리 위탁과 공유, 보관과 삭제,
  이용자의 권리, 아동의 정보, 보안, 정책 변경, 문의
- Google 사용자 데이터의 접근·사용·저장·공유 방식을 별도 섹션에서 직접 설명한다.

### 서비스 이용약관

- 신호색: `violet`
- 섹션: 서비스, 계정, 유료 서비스, 이용 제한, 지식재산권, 책임, 변경과 종료, 준거와 문의
- 개인정보처리방침과 구조는 공유하되 신호색과 문서 제목으로 구분한다. 색만으로 문서를 구분하지 않는다.

### 계정 및 데이터 삭제

- 정책 문서가 아니라 행동 안내 화면이다.
- 단계: 앱 설정 열기 → 계정 및 데이터 삭제 선택 → 삭제 범위 확인 → 삭제 요청 완료
- 삭제 범위는 `이 앱 데이터`와 `전체 픽셀로직 계정`을 나란히 설명하고 라벨·제목·목록으로 구분한다.
- 현재 앱이 마지막 활성 앱일 때만 전체 계정 삭제로 승격된다는 안내를 단계와 범위 선택 가까이에 둔다.
- 로그인할 수 없는 사용자를 위한 이메일 문의를 마지막 보조 행동으로 둔다.
- 웹 화면에서 삭제를 흉내 내는 입력이나 가짜 완료 상태를 만들지 않는다. 실제 삭제는 앱 안의 인증된 흐름이 소유한다.

## 모션

### 첫 진입

1. `0–240ms`: 헤더 기준선과 PL 모노그램이 한 픽셀 단위로 열린다.
2. `160–720ms`: 제목은 단어가 아니라 기준선 단위로 위로 드러난다.
3. `360–1,200ms`: 작은 픽셀이 제품 창 자리로 이동해 외곽선을 만든다.
4. `720–1,600ms`: 제품 화면이 헤아림 사주 → TalkTalk → Orbit → SideQuest 순서로 연결된다.
5. 이후: 궤도선과 연결점만 8–14초 주기로 아주 느리게 호흡한다.

### 상호작용

- 제품 창 호버: 180ms 동안 4px 상승하고 해당 연결선만 밝아진다.
- 제품 창 포커스: 호버와 같은 정보를 키보드에서도 제공하며 외곽선이 유지된다.
- 스크롤 진입: 제품 설명은 80ms 간격으로 순차 등장하되 위치 이동은 12px 이하로 제한한다.
- 테마 전환: 배경과 선 색만 240ms 교차하고 제품 이미지는 번쩍이지 않는다.

### 접근성

`prefers-reduced-motion: reduce`에서는 픽셀 이동, 궤도 회전, 시차 효과를 모두 끄고 120ms 이하의 불투명도 전환만 사용한다. 모션이 없어도 브랜드·제품 관계와 현재 포커스가 동일하게 읽혀야 한다.

## Google OAuth 브랜딩 심사 적용

- 홈페이지는 로그인 없이 공개한다.
- OAuth 동의 화면의 앱 이름 `픽셀로직`과 홈페이지의 대표 이름을 일치시킨다.
- OAuth 동의 화면에 올리는 로고와 홈페이지의 PL 브랜드를 일치시킨다.
- 홈페이지 URL은 다른 도메인으로 리다이렉트하지 않는 정적 URL을 사용한다.
- 개인정보처리방침과 서비스 이용약관은 홈페이지와 같은 소유 도메인에 둔다.
- 홈페이지와 OAuth 동의 화면의 개인정보처리방침 URL을 정확히 일치시킨다.
- 개인정보처리방침에는 실제 Google 사용자 데이터의 접근·사용·저장·공유 방식을 공개한다.
- Search Console에서 프로젝트 소유자 또는 편집자 계정으로 도메인 소유권을 확인한다.

시안은 위 요건을 보이게 만드는 디자인 기준이며, 실제 심사 통과는 구현·배포·도메인 확인·정책 내용·OAuth 설정이 모두 일치해야 한다.
