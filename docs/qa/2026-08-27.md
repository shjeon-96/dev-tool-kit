## 1차 캡처와 수정

| 위치                | 발견한 결함                                               | 적용한 규칙                                          | 수정                                          |
| ------------------- | --------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------- |
| 홈 히어로 제목      | 한국어 `오래`가 글자 중간에서 분리됨                      | 제목은 의미 단위로 읽혀야 함                         | 쉼표 기준 두 줄과 `word-break: keep-all` 적용 |
| 전역 브랜드 마크    | 첫 글자가 `P`보다 `F`에 가깝게 읽힘                       | OAuth 화면과 홈페이지가 같은 고유 브랜드를 보여야 함 | 닫힌 P 카운터가 있는 `PL` 경로로 교체         |
| 정책 모바일 헤더    | 축소 시 브랜드 마크가 압축되어 잘림                       | 하위 화면에도 명확한 이탈과 브랜드 필요              | 브랜드 열의 최소 폭 56px 고정                 |
| 다크 홈 제품 별자리 | Orbit·SideQuest가 캡처 순간 늦게 로드됨                   | 첫 화면의 주인공이 빈 상태로 보이면 안 됨            | 첫 화면의 제품 이미지 네 장 모두 우선 로드    |
| 테마 초기화         | 초기 스크립트가 `data-theme`을 바꾸며 hydration 경고 발생 | 의도된 클라이언트 초기값 차이는 정확한 경계에서 처리 | `<html>`에 `suppressHydrationWarning` 적용    |

확인 결과:

- 홈의 브랜드, 기능 설명, 실제 제품 네 개와 Google 데이터 이용 문구가 로그인 없이 첫 화면에서 읽힌다.
- 개인정보처리방침·약관·삭제 안내가 같은 브랜드 셸과 정책 푸터를 사용한다.
- 정책 화면에는 홈페이지로 돌아가는 명시적 링크가 있고 루트 홈에는 의미 없는 백 버튼이 없다.
- 모바일 390px에서 가로 문서 스크롤 없이 제목·CTA·제품 창·정책 목차가 유지된다.
- 라이트·다크에서 텍스트, 구분선, 제품 신호와 포커스 표시가 색 이외의 형태·라벨과 함께 제공된다.

## 접근성·모션

- 건너뛰기 링크, 시맨틱 제목 계층, 내비게이션 라벨, 이미지 대체 텍스트를 확인했다.
- 테마 버튼과 주요 링크는 최소 44×44 CSS px 목표를 사용한다.
- `prefers-reduced-motion: reduce`에서 제품 창의 계산된 `animation-duration`과 `transition-duration`이 각각 `0.000001s`로 축소됨을 실제 브라우저에서 확인했다.
- 전역 지침에 따라 최대 글자·시스템 폰트 최대 배율 테스트는 실행하거나 추가하지 않았다.
